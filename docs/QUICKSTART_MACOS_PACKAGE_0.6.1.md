# Auto Research macOS 0.6.1 内部预览：安装、导入、搜索

本套件仅供课题组内部测试。App 与官方资料包是两个独立文件，今后可以分别更新。

## 1. 安装 App

1. 双击 `Auto-Research-0.6.1-preview.1-macOS-arm64.dmg`。
2. 将 `Auto Research` 拖入“应用程序”。
3. 从“应用程序”打开 `Auto Research`。内部未公证预览首次打开时，macOS 可能要求确认；不要关闭系统安全功能。

## 2. 导入官方资料包

1. 在左侧打开“搜索数据”。
2. 在页面上方“官方资料库”卡片点击“选择资料包”。
3. 选择 `auto-research-internal-evidence-0.2.0-preview.1.aresearch`。
4. 等待验证、安装、仓库审计和启用完成。

首次导入显示“已安装并启用”；再次选择同一文件会显示“当前版本已经启用”，这也是成功结果，不会重复复制数据。

## 3. 搜索

1. 打开“搜索数据”。
2. 选择“精确检索”和“离线资料库”。
3. 选择“官方文献”，输入材料、实验条件、物理量、题目、DOI 或作者。
4. 结果仍只有数据条目、结论、表格和图片四类；没有随包提供的 PDF 或截图会明确显示不可打开。

## 4. 校验下载文件

`SHA256SUMS.txt` 记录 App、资料包和发布 ZIP 的 SHA-256。若文件校验值不同，请停止使用并重新获取。

## 5. 出现错误时

请记录“错误码、阶段和结果”，不要只截取“导入失败”四个字。重新导入时必须重新点击文件选择器，不要重复使用上一次的选择状态。

旧官方包 `0.1.0-preview.1` 保持不变并单独保存为工程回退点；本套件默认只附带新版 `0.2.0-preview.1`。
