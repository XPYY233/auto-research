# ADR 0001：拆开规则、投影与编排

问题：科学提取/质量读取、XLSX 导出、AI 错误及传输包互相依赖；旧扫描器将包导入错误展开到所有兄弟模块，且允许旧循环复活。

决定：独立 candidate_matching、element_search、quality_lookup、xlsx_export、provider_errors 和 transfer_package_planning。
旧入口保留兼容导出；AI/settings 包采用按需导出，避免导入提供商时立即加载设置控制器。
匹配、质量投影、XLSX、错误及传输规划共 45 个迁移定义经 AST 比较与原定义一致。
质量图片读取改用工作区路径，显式 EvidenceDB 不再创建另一工作区目录。

门槛：准确解析绝对/相对具名导入及跨包初始化；共享源码静态依赖循环必须为零。
动态插件加载不在该静态证明范围。逐文件责任检测必须无遗漏、无同等具体程度的歧义。
该拆分不等于 Fusion、旧 Web 控制器继承或加密存储整合已经完成。

验证：统一离线检查，共享 1382 项、Mac 339 项通过，81 项私人历史语料单独排除。
兼容导出逐项身份验证、真实档案安全检查与后端 DTO 到生产 UI 测试保留。
不更改数据库 schema、科学字段、官方包或私人密文。回退通过 PR revert，不回写科研数据。
