# ADR 0002：空工作区与只读资源分离

问题：旧启动器自动查找开发目录，且冒烟复制维护者数据库并链接开发资产；已有 AI 凭据还被冒烟隐式依赖。

决定：默认在 Application Support/Auto Research/workspace 原子初始化真实空 schema v12。
命令行、环境变量或已保存的旧工作区优先；指定工作区不可用时停止，不偷偷切换到空库。
WorkspacePaths 分清 App 资源、工作区、私人状态、缓存和临时目录。配置读取打包资源；历史私人状态位置及密文保持兼容。
单进程路径只允许首次绑定，同一根可重复配置，不允许进程中切换资料库。

先在同卷暂存目录建立完整数据库、校验、同步文件，再原子改名。失败不覆盖已存在数据，
遗留暂存目录不自动激活。已有旧库仅只读校验；此变更不负责迁移旧库。
启动后暂保留工作区 CWD，以兼容旧记录的相对路径；逐业务替换仍由 #2/#3 跟进。

候选验证由候选自己建立新工作区，再运行真实 HTTP 冒烟并比较数据库哈希。
不复制开发数据库，不建开发资源符号链接。合成授权往返只用于冒烟，不能执行模型调用或激活真实用户 AI。

验证：空库创建/重启、坏配置不回退、未知数据和新 schema 不覆盖、初始化中断重试、资源绑定及真实本地 HTTP。
源码无凭据空库冒烟已通过；不等于冻结 App 或第二台 Mac 验收。
