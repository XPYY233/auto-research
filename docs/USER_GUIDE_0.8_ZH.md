# Auto Research 0.8 用户使用指南（macOS 内部预览）

> 适用版本：Auto Research 0.8.0-preview.1（Apple Silicon Mac）
> 发布边界：课题组内部预览，临时签名，尚未经过 Apple 公证；Windows 安装版另行验收。

## 1. 先认识交付文件

最终用户套件中会包含：

- `Auto-Research-0.8.0-preview.1-macOS-arm64.dmg`：macOS 软件安装镜像；
- `auto-research-internal-evidence-0.2.0-preview.1.aresearch`：课题组签名的官方结构化资料包；
- `Auto-Research-Synthetic-Experiment-Example.aresearch`：不含真实科研数据的可分享示例用户包；
- `Sample-Experiment.csv`：用于练习实验数据识别和导入的合成表格；
- `SHA256SUMS.txt`：交付文件完整性校验值；
- `RELEASE_ACCEPTANCE.json`：版本与验收边界记录；
- 本指南。

官方资料包、用户资料包和 App 是三个独立对象。更新 App 不会自动覆盖资料包；导入用户资料包也不会修改官方资料库。

## 2. 安装并避免旧版干扰

1. 完全退出正在运行的 Auto Research。
2. 弹出所有旧的 `Auto Research Preview` 安装镜像。
3. 打开新的 DMG，把 `Auto Research.app` 拖到“应用程序”。
4. 如果系统询问是否替换旧版，选择“替换”。不要保留两个同名可启动 App。
5. 从“应用程序”文件夹启动，不要从 DMG、下载目录、旧 Dock 副本或回退目录启动。
6. 因为内部预览尚未公证，首次被 macOS 拦截时：关闭提示，在“应用程序”中按住 Control 点击 App，选择“打开”，再次确认。不要关闭 Gatekeeper、XProtect 或其他系统安全保护。
7. 启动后核对右上角版本标记为 `0.8.0-preview.1`。如果版本不同，退出软件并检查是否启动了旧副本。

0.7 build15 会作为维护者回退点保存，不应与 0.8 同时作为可启动 App 出现在 `/Applications`。

## 3. 界面与快捷操作

左侧活动栏有四个科研入口：

- **文献**：导入 PDF、运行本地或受控 AI 抽取、核验结构化证据；
- **搜索**：精确检索官方资料、私人实验和导入的论文集合；图书管理员仅使用官方全库；
- **实验**：导入 CSV、TSV 或 XLSX，使用 AI 辅助预填，浏览后一次确认；
- **资料包**：管理官方版本、导出论文集合或私人实验、导入用户资料包。

常用快捷键：

- `⌘1` 至 `⌘4`：依次切换文献、搜索、实验、资料包；
- `⌘K`：打开命令与快速跳转；
- `⌘,`：打开设置；
- 在标签或列表中使用方向键、Home、End 移动焦点。

## 4. 日间、夜间与显示密度

打开活动栏底部的“设置”，在“外观”中选择：

- 主题：跟随系统、日间、夜间；
- 密度：舒适、紧凑；
- 语言：0.8 首版完整支持简体中文，英文仅在完整翻译后开放。

这些设置只改变界面，不会改变论文题名、实验数值、单位、搜索内容或导出文件。PDF 和论文图片保持原色，不做反色处理。

## 5. 配置 AI 提供商和 API 密钥

0.8 首版支持经过代码审查、固定官方端点的 Agent 模型提供商：DeepSeek 与 OpenAI。为防止 API 密钥被发送到伪造网址，普通用户不能填写任意服务器地址。以后可以通过软件更新增加新的受信提供商。

1. 打开“设置 → AI 与 API 密钥”。
2. 选择 DeepSeek 或 OpenAI，并选择软件提供的受支持模型组合。
3. 粘贴对应提供商的 API 密钥，点击“安全保存”。保存本身不联网，也不会产生模型费用。
4. 如果选择“测试连接”，软件会先说明仅发送固定健康检查短句且可能产生极少费用；取消则不会发出请求。

密钥不会回显，不进入资料包、科学数据库、对话历史或日志。DeepSeek 与 OpenAI 使用相互独立的凭据槽。离线精确搜索、资料包管理、本地预览和人工确认不需要 API 密钥。

AI 的三类主要发送边界：

- 图书管理员：研究问题和官方库中有界的结构化证据；
- 文献提取：选定 PDF 的有限页内文字、图注或表格文字及附近正文；
- 实验识别：工作表名、行列类型、已有单位、本地初步语义和最多 5 行样例。

路径、API 密钥、完整私人库和其他未选择的文件不会发送。每类功能首次调用及后续分阶段收费动作都会单独显示提供商、模型、发送范围、最大调用次数和令牌预算；只有用户确认后才执行。

## 6. 导入官方资料包

1. 打开“资料包”。
2. 点击“导入官方资料包”，选择套件中的 `auto-research-internal-evidence-0.2.0-preview.1.aresearch`。
3. 等待签名、校验值、权限、结构和仓库审计完成。
4. 成功结果可能是：
   - `installed`：首次安装；
   - `activated`：重新启用已经安装的版本；
   - `already_active`：相同资料包已经启用，这同样是成功。
5. 导入完成后进入“搜索”，用“硬度”“辐照温度”“钨”等关键词验证结果。

重复导入时必须重新选择文件，不要复用旧选择。失败时记录页面显示的 `code / stage / outcome`；失败不会覆盖旧目录，也不会改变当前可用官方版本。

## 7. 文献处理

1. 打开“文献”，选择“导入 PDF”。
2. 选择本机 PDF，等待验证和导入完成。
3. 在当前文章页浏览本地可获得的信息。
4. 需要 AI 的文献会进入分阶段流程。每个阶段都先显示本阶段发送范围、模型、最大调用次数和令牌预算；确认后才执行该阶段。
5. 只有最终页面明确显示“已提交”时，新的自动结果才已经原子写入证据库。取消、模型失败或质量门未通过不会留下半成品正式记录。
6. 自动通过的数据进入结构化证据；存在歧义的数据进入“需处理异常”，不会冒充已发布结果。

本地 curated 抽取或准备数据包等不调用模型的步骤不会弹出收费说明。

## 8. 上传并核验实验数据

建议先使用套件中的 `Sample-Experiment.csv` 完成一次练习：

1. 打开“实验”，点击“选择文件并自动识别”，再选择 CSV、TSV 或 XLSX。
2. 软件先在本机生成安全预览，不会立即建库。
3. 如需 AI 辅助，点击“让 AI 识别当前工作表”，阅读发送范围和费用说明后确认。切换工作表不会自动再次收费。
4. 检查 AI 预填的项目、样品、实验批次、列角色、含义、单位和测量序列。AI 建议始终是待核验内容，不能自行确认。
5. 需要修改时直接编辑；忽略列只需确认其角色，不要求填写意义或单位。
6. 页面底部只做一次“我已检查，确认导入”。后台会原子完成草稿、版本比较和确认，不要求用户理解内部步骤。
7. 成功后软件切换到“搜索”，范围为“我的实验”，并显示刚导入的结果。

如果 AI 不可用，仍可使用本地初步识别和人工编辑完成导入。私人搜索刷新失败时，数据仍已保存；使用“重试搜索刷新”，不要重复确认导入。

## 9. 搜索与图书管理员

“精确搜索”可以选择：

- 全部：官方资料 + 私人实验 + 导入的论文集合；
- 官方资料；
- 我的实验；
- 指定的只读论文集合（若已导入）。

结果实体固定为数值条目、定性结论、表格、图片四类。搜索不会把不同来源在前端自行合并，统一排序由后端完成。

“图书管理员”是只读的官方全库研究助手，不读取私人实验或用户论文集合。系统能力问题和普通问候不检索论文、也不调用模型；研究问题才进入有界检索与逐阶段授权。R# 和 B# 用于继续追问当前证据和证据组。

## 10. 导出与分享资料包

### 导出论文集合

可选择逐篇论文、当前筛选结果或证据库全部论文。包中包含元数据、已发布四类证据、受预算限制的短摘录和符合规则的 PDF：

- 明确开放许可且已验证的 PDF 可以自动包含；
- 其他 PDF 必须逐篇确认具有课题组内部分享权限；
- 缺 PDF 的论文仍可导出元数据和证据；
- 首版不包含图表截图；
- 单包上限 2 GB，超限时需要减少选择。

### 导出我的实验

只导出 `confirmed + indexable` 的项目、样品、实验批次、条件、测量定义、备注和对应原始 CSV/TSV/XLSX；不含草稿、AI 建议、会话、暂存文件、路径、内部主键或实验图片。

### 用户包安全提示

用户包：

- 未加密；
- 来源未认证；
- 仅提供 SHA-256 完整性校验；
- 仅限课题组内部。

SHA-256 只能帮助发现文件损坏或是否与对方手中的文件一致，不能证明发送者身份，也不能保护文件泄露。真实分享时，应通过独立渠道与发送者核对完整的 64 位 SHA-256；不要把与包放在同一个压缩文件里的 `.sha256` 当作身份凭证。

导入用户包前，选择包文件、粘贴独立渠道获得的完整 SHA-256，并确认“已核对校验码”“理解未加密”“理解来源未认证”“仅限组内”。用户包永远不会成为官方资料，也不会进入图书管理员。

相同用户包重复导入返回 `already_present`；内容冲突默认拒绝，只有显式选择“冲突时保留两份”才会建立稳定的独立副本。

## 11. 常见问题

### 页面空白或内容迟迟不出现

- 先切到其他活动，再切回来；
- 确认设置中的版本是 0.8.0-preview.1；
- 如果只有资料包状态失败，实验和离线搜索仍可使用；点击资料包页的“重试”；
- 完全退出 App，确认没有从旧 DMG 启动，然后从 `/Applications` 重开。

### 已安装版本一直读取

新版会把资料包服务故障与“尚未安装”分开显示。点击重试；如果仍失败，记录稳定错误码，不要重复删除数据目录。

### AI 提示未配置或验证失败

- 确认选择了与密钥匹配的提供商；
- 确认已安全保存，而不是只粘贴在输入框；
- OpenAI 首次使用需要完成一次明确的连接与能力验证；
- 网络、额度、限流或密钥错误会显示稳定类别；不会把底层响应或密钥显示在页面。

### 私人数据已保存但搜不到

在实验页点击“重试搜索刷新”。不要重新确认导入。旧私人搜索源在刷新失败时会保留。

### 如何回退

如果 0.8 出现阻断问题：

1. 退出 App；
2. 联系维护者取回 0.7 build15 回退 App；
3. 把 0.8 从 `/Applications` 移开，再放入回退 App；
4. 官方资料包可在“资料包”中选择仍保留且审计通过的旧版本回退；
5. 不要手工修改 `active.json`、SQLite 或资料包安装目录。

## 12. 版本边界

- macOS：本套件是 Apple Silicon 课题组内部预览，临时签名，未公证；
- Windows：0.8 只提供源码与构建预览套件，`installer_ready=false / SETUP_PRESENT=NO`，需要在真实 Windows 11 上生成并验收 Setup 后才算安装版；
- 软件稳定、语料完成度和科学准确性是三件不同的事。App 可用不表示所有论文已经抽取完成，也不表示自动候选无需科学核验。
