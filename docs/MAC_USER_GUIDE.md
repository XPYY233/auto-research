# Auto Research Mac 候选版使用说明

适用：Apple Silicon，当前只实测 macOS 26.3.1。候选版使用临时本机签名，未经过 Apple 公证；此说明不代表正式发布验收完成。

## 首次使用

打开 App 后会在用户的 Application Support/Auto Research/workspace 建立空工作区。无需安装 Python、源码、Zotero 或维护者数据库。已存在的工作区沿用保存位置；位置无效会明确提示，不偷偷建立另一个空库。

选择“导入 PDF”，核对文章身份与预检结果。在“设置”配置自己的模型服务后，才能开始需要付费的提取；每次调用需按软件提示授权。跨电脑不要复制 API 凭据。

## 找不到图片或表格

先查看提取收据，再打开“待审核”。原图已经保存、但图注或结构尚未确认时，会留在待审核列表，不进入正式检索。

在候选详情中查看“待审核原图”、图注及来源页。与原文逐项核对后再批准、纠正或不采用；审批会记录版本。图片原样显示不等于曲线点已数字化。正文没有独立表格时，表格数量可以为零。

凭证过期或原图无法读取时，刷新待审核列表重试；不应为此重新执行整篇付费提取。发布已保存但索引失败时，使用“恢复搜索索引”。

## 保存和回退

科研数据、私人库和加密历史在 App 外部；删除 App 不应手动连带删除 Application Support 或原工作区。完整备份须包含数据库、原图/PDF、私人密文及对应恢复密钥；单独复制数据库不能保证恢复。

候选身份见 App 内 desktop-build-manifest.json，安装包名包含 candidate_id。维护者应保留旧 App 和数据快照；出现问题先回退 App，不用旧数据库覆盖最新科研记录。

## 当前限制

第二台干净 Mac、完整功能联合验收、人工科学金标准和组内分发许可还未全部收口。请按候选版使用，不把工程检查通过当作科学数据全部正确。
