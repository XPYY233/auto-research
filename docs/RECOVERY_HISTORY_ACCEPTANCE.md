# 长任务历史与恢复验收（公开 #11）

2026-09-22。关联公开 #2 核心联合验收；本记录目前证明源码行为，不冒充日常安装版验收。

## 复现

5 个新增行为用例在修改前失败：128 条历史的容量判断阻止新提取；较老活动任务被前 128 条挡住；目录只取最近记录，旧未完成任务不显示；启动恢复的有限名额被最近已结束记录占满。

## 改动

- 加密存储增加完整分页遍历，固定起始记录范围，以稳定任务 ID 排序，每页最多 128 条；页与页之间关闭读取连接，恢复写入不被长读锁阻塞。
- 重复收费防护逐条验证全部历史，不因已结束历史数量拒绝新任务；旧活动任务仍阻止重复准备。
- 目录保留有界显示数量，但活动任务优先于已结束历史，同类按更新时间排列。
- 启动恢复扫描完整历史，待完成发布和已完成收据/快照清理分别保留有界名额。只有已验证或发布中任务走本机恢复，不触发模型调用；质量未通过或调用结果未知仍不可直接发布。
- 检查点编解码从 SQLite 存储拆出，序列化格式与加密关联数据不变，不修改 schema 或清理用户历史。

## 验证

- 260 条真实加密 SQLite 记录的多页遍历、遍历期间恢复写入、排除扫描开始后新插入记录、关闭重开存储均通过。
- 131 条真实加密任务历史中，重开存储后找到旧已验证任务；同文献新任务仍被阻止、其他文献可准备；恢复及重复恢复只调用一次本机 finalizer，历史记录和已花费调用数保留。
- 序列化固定样本与拆分前 SHA-256 完全相同，编解码往返通过。
- 统一工程检查：1450 项共享测试、374 项 Mac 测试通过；私人语料 81 项显式不选中，1182/245 个子测试通过。完整日志仅留本机，公开不含资料和凭据。
