# 个人实验数据：首版功能边界

## 用户要完成的事

一线实验人员完成测量后，可以导入自己整理的 Excel/CSV 数据表，并可附带已经画好的趋势图。软件先展示列名、样例值、数据含义、单位和实验条件，请用户确认后再进入“我的实验”检索。用户不需要先写成论文，也不需要理解 AI 或数据库。

## 首版流程

1. 选择 Excel/CSV，软件保留原始文件的不可变身份（文件名、大小、哈希），内部路径不进入搜索结果。
2. 为每个工作表生成导入预览，只展示少量样例值，不在预览阶段写入个人数据库。
3. 用户确认每列角色、物理意义和单位；数值列的单位即使为空或无量纲，也必须明确确认。
4. 用户补充项目、样品、实验批次、方法、条件和备注，并确认哪些列组成一条测量序列。
5. 趋势图可关联到已确认的测量序列；默认只保存图和用户说明，不自动从曲线猜测数据点。
6. 全部问题消除且用户明确确认后，才生成私有搜索文档。草稿、拒绝项和含义未确认的列不进入搜索。

## 搜索与图书管理员

用户始终使用同一个入口，并可选择“文献数据库 / 我的实验 / 两者一起”。已知样品号、批次号、文件名或明确关键词时走精确搜索；比较、解释、趋势总结等问题交给图书管理员。自动判断只是默认值，用户可以手动切换。

个人实验搜索文档使用 `source_domain=personal`、`source_scope=private` 和稳定 `entity_uid`。个人记录使用 `record_type`，不冒充文献的 `item/table/figure/finding`，也不写入论文六列事实表。未来“文献 + 我的实验”的回答必须分别标明来源，禁止把用户测量值误写成论文结论。

## 当前尚未实现

- 尚未读取真实 Excel/CSV，也未创建个人数据库或文件仓库。
- 尚未提供仪器原始格式导入、多人协作、版本冲突处理或云同步。
- 尚未从用户趋势图数字化曲线；如果以后增加，必须是单独确认和审核的流程。
- 尚未接入 App 界面。macOS 和 Windows 桌面任务只需消费平台中立契约，不在各自客户端复制科学逻辑。
