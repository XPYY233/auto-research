# 图书管理员检索修复说明（2026-07-29）

## 用户看到的问题

页面看起来只给了两条证据，但后台实际上已经找到十八条。原因是页面停留在“表格”分类，而这一类恰好只有两条；同时 DeepSeek 的最终总结没有成功，所以回答区只剩下机械的数量提示。

## 现在如何工作

1. DeepSeek 先把自然语言问题拆成若干个短检索问题。
2. 程序自动搜索数据条目、表格、图片和结论，不依赖模型决定是否搜索。
3. DeepSeek 检查候选是否真正满足材料、辐照类型和物理量等条件，再组织中文回答。
4. 页面同时显示“共召回多少项”和“回答引用多少项”。被回答直接引用的卡片排在前面，其他相关记录仍可继续查看。
5. 相同问题在数据库没有变化时复用整套已验证结果，避免同一句话重复提问却出现不同引用数量，也减少重复调用费用。

## 真实验证

同一个“高熵合金中子辐照后的硬度与缺陷结构”问题现在稳定召回五十八项候选。发布服务的参考回答引用六项；第二次相同请求的回答、引用和候选校验完全一致。页面仍展示其余候选，并明确区分“回答引用”和“扩展候选”。系统没有把离子辐照冒充为中子辐照，而是明确说明当前数据库缺少直接证据。

本轮没有重新提取论文，也没有修改数据库中的科学事实、图表或人工校对记录。
