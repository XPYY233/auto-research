# 本机加密身份兼容（公开 #13）

2026-09-22。应用标识同时参与 AES-GCM 认证数据和 Keychain 服务名；源码净化时更改标识并非单纯改名。build58 在空工作区构建、HTTP 和重启检查通过，但对既有数据备份解密失败。该候选不予接受，日常 App 已恢复 build57；未以 build58 启动生产工作区。

## 兼容办法

从升级前保留的 App 读取历史应用标识，以原子、只创建一次的方式保存在本机 `Private Data/crypto-identity-v1.json`，权限 0600。后续升级保留已有记录；公开新用户没有该记录时使用公开应用标识。损坏或符号链接记录必须报错，不得悄悄回退身份。

各类历史、活动记录、官方表格隔离记录、API 凭据和提取断点共用这一身份来源。密钥、密文、关联数据算法、数据库格式不改写，旧 App 仍可读取原始数据。旧身份不写入源码、构建资源、GitHub 日志或公开报告；仓库检查禁止提交身份记录文件。

事务安装器在替换旧 App 前保存身份。Finder 手动升级按 README 先运行身份保存命令；已覆盖 App 的用户需使用升级前 App 副本。跨机器仍需保留恢复材料并重新配置 API 凭据，不保证仅复制数据库即可读取本机历史。

统一工程检查：1451 项共享测试、383 项 Mac 测试通过（1182 / 245 子测试）。

## 已验证的边界

- 合成回归覆盖首次使用、重复升级、公开新标识不能覆盖旧身份、原密文不变、损坏/符号链接拒绝，以及全部 8 类加密适配器的 10 个认证域和 Keychain 服务名。
- 真实备份副本中：5 条提取断点（4 完成、1 取消）、6 类历史适配器加载和 1 份现有提供商凭据读取通过。所有原私人文件及密钥哈希不变。原始载荷及详细本机记录不上传。
- 这是同机恢复兼容证据，不代表第二台 Mac、科学准确率或所有功能已完成验收。后续候选身份与安装结果见当前交接记录。
