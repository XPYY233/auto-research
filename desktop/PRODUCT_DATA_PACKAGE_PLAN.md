# Auto Research 桌面产品与数据包方案

更新时间：2026-08-01

## 产品定位

- 当前 macOS App 是开发和验证预览，不是最终唯一平台。
- 正式用户端优先目标是 Windows；共享核心、数据包和用户资料库必须跨平台。
- 唯一用户产品是个人科研工作台 App。浏览器工作台、导师只读、8765/8766 和 ngrok 不再作为产品入口。
- App 内部可以继续使用仅绑定 `127.0.0.1` 的页面服务作为界面实现，但用户不需要理解或操作端口。

## 用户第一次使用

1. 下载并安装 Auto Research。
2. 点击“导入资料包”。
3. 选择我们提供的 `.aresearch` 文件。
4. App 在隔离区检查版本、文件清单、哈希、签名和资源路径。
5. 检查通过后，把资料包作为只读官方资料库安装到用户数据目录。
6. App 在本机建立可重建搜索索引。
7. 用户立即进行离线精确搜索；此步骤不需要 API 密钥，也不需要开发者电脑在线。

导入失败必须保持原资料库不变，并用非技术语言说明原因和恢复方法。

## 三类数据必须分开

| 数据层 | 内容 | 更新与安全规则 |
|---|---|---|
| 官方资料包 | 可公开的结构化证据、来源身份、经审核资源 | 只读、版本化、可校验、可回退 |
| 用户私人库 | 用户自行上传的 PDF、抽取结果和人工修正 | 只保存在用户设备，官方包更新不得覆盖 |
| 本机应用状态 | 设置、缓存、日志、对话历史、凭据引用 | 与科学数据分离，可清理但不可泄露密钥 |

搜索层可以联合展示官方包和私人库，但不得把两者物理合并成一个会被升级覆盖的数据库。

## `.aresearch` 数据包草案

```text
official-fusion-materials-2026.1.aresearch
├── manifest.json
├── checksums.json
├── signature.json
├── evidence/evidence.sqlite
├── assets/...
├── rights/licenses.json
└── provenance/sources.json
```

`manifest.json` 至少包含：

- `package_id` 和不可变版本；
- 证据 schema 与最低 App 版本；
- 论文、证据和资源数量；
- 创建时间与发布者身份；
- 权利范围；
- 每个资源的包内相对身份，不允许绝对路径；
- 是否包含可再分发 PDF、图片或短摘录。

默认公开包不得包含：

- 本机绝对路径；
- Zotero key 或设备身份；
- 用户对话、审核者身份或内部备注；
- 开发者或用户 API 密钥；
- 未经权利审查的完整 PDF、截图和长摘录；
- 可执行脚本、软链接或越出解压目录的路径。

## PDF 与版权

- 明确允许再分发的开放许可 PDF，可以经过逐篇审查后进入可选来源包。
- 只能阅读但未允许再分发的论文，不打包全文；保留 DOI、题目、页码和来源入口。
- 机构订阅、付费或私人论文只能由用户自行合法导入。
- 没有 PDF 时仍允许搜索结构化证据；“查看原文”应提示打开 DOI 或关联用户自己的 PDF。

## API 密钥与非 AI 用户引导

### 不需要密钥的功能

- 导入官方资料包；
- 离线精确搜索；
- 浏览已包含的证据、表格、图片元数据和研究简报；
- 导出不涉及新模型调用的结果。

### 需要密钥的功能

- 上传新 PDF 后运行 AI 抽取；
- 图书管理员自然语言问答；
- 对选中证据进行新的 AI 解释。

第一次触发 AI 时，界面显示四步引导：

1. 说明“API 密钥是 AI 服务的通行证，不是 Auto Research 密码”。
2. 明确接收方、预计发送的数据：图书管理员发送问题和有限证据；抽取发送所选 PDF 的有限页块。
3. 提供“粘贴密钥—检测连接—保存到系统安全凭据库”的连续操作，不要求用户编辑环境变量。
4. 提供“暂不配置”，并保证离线搜索继续可用。

密钥只能存入操作系统安全凭据库：

- macOS：Keychain；
- Windows：Credential Manager；
- 后续 Linux：Secret Service/libsecret。

密钥不得写入 SQLite、日志、`.aresearch`、导出文件或崩溃报告。

内测阶段不得把一个无限额开发者主密钥发给所有人。应为每位测试者提供独立、可撤销、有限额的密钥。正式版选择用户自己的密钥，或未来建设带账户、配额和审计的模型网关。

## 更新与回退

- App、官方资料包、用户私人库分别版本化。
- 新包先下载到隔离目录，全部校验通过后原子切换。
- 旧包保留一个可恢复版本。
- App 升级不得静默迁移或覆盖用户私人 PDF、人工修正和不可变证据历史。
- 搜索索引只是可重建投影，不进入资料包的科学权威层。

## 第一阶段验收

- 一台没有开发项目目录的干净电脑能够安装 App；
- 导入一个测试 `.aresearch` 包后可以离线搜索；
- 没有 API 密钥时所有非 AI 功能正常，AI 按钮给出清楚引导而不是报错；
- 粘贴测试者自己的密钥后，能运行一次图书管理员查询和一次私人 PDF 抽取；
- 官方资料包更新不会改变私人库；
- 损坏、签名错误、版本不兼容和路径越界的包均被拒绝；
- 删除密钥后离线搜索仍可用；
- macOS 预览和 Windows 正式版读取同一份跨平台数据包契约。

## 本轮稳定 App 不扩大实现范围

当前低负载收口只完成：稳定 macOS 开发预览、桌面唯一入口、无密码弹窗、研究简报、应用图标和可回退发布。`.aresearch` 导入器、API 密钥设置向导和 Windows 包装器作为下一产品阶段实现，避免在尚未冻结的核心上继续叠加高风险改动。
