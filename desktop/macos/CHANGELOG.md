# macOS Desktop Changelog

## 1.1.0 build 25 candidate — 2026-08-22

- 分栏升级为 `fusion-pane-layout-v2`：侧栏和任一编辑组可吸附收起并恢复，不删除标签或滚动状态；窄栏使用容器查询，避免标题逐字竖排。
- 文献与搜索单击证据会在宽屏自动打开右侧预览；双击、提问和PDF会固定标签。重新打开关闭标签移入标签菜单与命令面板，移除含糊的主工具栏图标。
- 新增 `ai-readiness-v1` 和真实API管理中心，分别展示连接、Harness与四项业务状态；支持DeepSeek、OpenAI及通过SSRF/DNS重绑定安全门的公开HTTPS OpenAI-compatible服务。
- 修复AI错误血缘和本地前置检查顺序；取消连接/能力验证不会发出业务请求，Harness不可用时本地搜索、PDF、导入和导出继续可用。
- 源码已通过共享896项与macOS 236项测试；真实App、真实DeepSeek付费验收、签名与DMG尚未完成，因此本条仍是候选而非稳定发布。

## 1.1.0 — 2026-08-22

- 文献目录成为独立滚动区，新导入论文自动选中并滚动到可见位置；四类证据改为真实服务端多选筛选，不在有限前端结果中假过滤。
- 文献目录恢复题目、作者与 DOI 快速筛选；搜索主输入框和服务端分页恢复，工具栏不再挤压搜索入口。
- Fusion 引入可恢复的 `DocumentTabStore`：论文、证据、PDF、私人实验表格和资料包任务均可独立打开；最多两个编辑器组，异步结果不能抢夺当前标签。
- 新增真实待审核队列：主候选/备选并列查看，支持批准、不采用和受限字段纠正；科学记录与搜索索引采用“已保存/索引待恢复”两阶段诚实状态。
- 文献、搜索、实验、资料包、设置共用一个物理检查器但保存五套隔离状态，杜绝跨模块残留。
- 图书管理员和选中证据问答迁移到精确锁定的 DeepSeek Harness；composition 不提供 Shell、文件系统、PTY、编辑器、子 Agent 或任意网络工具。旧收费接口固定退役，不作为故障回退。
- Harness 会话使用本机加密历史，默认最多20个会话或30天；逐次授权、提供商/模型白名单、token/调用预算和凭据仍由 Auto Research 掌握。
- 新增 `official-package-v2` 输入审计、PDF/视觉资产/来源锚点能力和导入后的数量、PDF覆盖与“前往搜索官方资料”动作；任一无效PDF、资源变化或超过2GB均失败关闭。
- 官方 `1.1.0` 包明确为 59 篇：排除无法取得真实 PDF 的 DOI `10.2172/6065200`，其余 59 份 PDF、291 个图表资产及4,369条四类证据均通过构建与安装后运行时校验。
- 新增 `dataset-bundle-v1`：JSONL、真实 Parquet、数据卡、manifest、确定性论文级 train/validation/test 划分和原子导出；默认不复制PDF/图片或私人实验。
- 新增独立科学发布审计，分别度量数值、单位、意义、条件、表格、图片、结论、片段和定位，不把软件测试通过当作科学准确率。
- 本轮仅发布 Apple Silicon Mac；Windows 1.1迁移冻结到用户认可Mac主流程之后。App继续使用 ad-hoc 签名且未经 Apple 公证。

## 1.0.0 — 2026-08-21

- 发行身份升级为 macOS `1.0.0` / build `22` 课题组稳定版，目标设备为 Apple Silicon Mac。
- Fusion 科研工作台作为唯一主界面，集中承载文献导入与分阶段提取、四类证据详情、精确检索、Librarian V3、个人实验导入、资料包管理和 BYOK 设置。
- App 与 DMG 使用 ad-hoc 签名，未使用 Developer ID，未经 Apple 公证，不通过 App Store 分发。
- 首次打开如被 Gatekeeper 拦截，使用访达的 Control 点击“打开”，或在“系统设置 → 隐私与安全性”中选择“仍要打开”。
- Windows 开发与发布暂停，本版没有 Windows 安装包。
- 科学 SQLite、PDF、图片、用户私人库和开发者凭据不打包进 App；稳定发行不代表固定语料已全部完成或科学内容已全部人工验证。

## 0.4.0-preview.1 — 未发布

- 新增 macOS 原生 `.aresearch` 文件选择器；网页只接收短期 `selection_id`，不接收或返回本机路径。
- 官方资料包由共享核心统一验证发布者策略、签名、哈希、身份、权利范围与只读仓库；桌面层不维护自己的信任白名单。
- 保留 v12 本机可编辑维护工作区，同时把官方资料包作为第二个不可变来源；二者不复制、不覆盖。
- 新增官方资料库/本机工作区来源切换和四类横向检索；官方结果只使用 `source_scope/source_id/entity_uid`，不伪造本机数字 ID。
- 资料包不含 PDF 或图片二进制时，相应按钮明确禁用，仍展示题目、DOI、页码、图注或原文摘录。
- 新增 DeepSeek BYOK 状态、保存与删除引导；离线搜索无需 API 密钥。
- 桌面版本只从 `version.json` 读取，DMG 文件名随版本生成，保留 `0.3.0-preview.1` 回退身份。

本节仅记录已经完成定向测试的开发候选；尚未执行最终 App 构建、DMG、全套测试或实机验收。

## 0.3.0-preview.1 — 2026-08-01

- 将产品入口收敛为个人科研工作台 App；旧浏览器、导师只读和 ngrok 启动器只保留迁移提示。
- 集成核心提交 `9aa461a` 的签名研究简报与桌面产品契约。
- 加入新的 Auto Research 书页、证据节点与验证标记图标。
- 修复 ad-hoc 重建后 macOS 索要“登录钥匙串密码”的问题：预览版不读取或删除旧 Keychain 项。
- 历史继续使用 AES-256-GCM；预览期随机密钥保存在 Application Support 私有目录并限制为 `0600`。
- 明确当前只交付稳定 macOS 演示版；路径、资料包与安全凭据接口为未来 Windows 留出迁移边界，但本阶段不开发 Windows。
- 固化 `.aresearch` 官方资料包、用户私人库、本机状态和 BYOK 的分层方案。

本版本仍依赖开发机项目目录，且未正式签名、公证；它是稳定演示候选，不是可公开分发的最终产品。

## 0.2.0-alpha.1 — 2026-07-30

- 修复关闭并重新打开 App 后图书管理员对话历史消失的问题。
- 保持 pywebview 私人模式，不使用持久化浏览器 localStorage 保存科研对话。
- 使用 macOS Keychain 保存设备本地 AES-256 密钥。
- 使用 AES-256-GCM 将会话正文、回答、结果和元数据认证加密后写入 Application Support。
- 加密历史与科学 SQLite、PDF、搜索索引和模型缓存分离。
- 桌面会话接口继续受随机 loopback 端口、HttpOnly Cookie 和同源检查保护；普通浏览器和公开只读服务没有该接口。
- 加密层不可用时 fail closed：显示警告且不降级为明文持久化。

本版本仍是私人 macOS Alpha。加密本地历史不能替代正式代码签名、公证、威胁建模和公开发布安全审计。

- 用真实 HTTP 响应验证 CSV、XLSX、Markdown 和 JSONL 四类导出。
- 添加 Apple Silicon PyInstaller `.app` 构建、验证和 DMG 入口。
- 添加工作树干净检查、更新前 SQLite 备份、上一版应用保留和安全更新入口。
- 每次构建在应用内部写入核心 commit、核心版本、数据策略和工作树状态清单。
- 添加面向非软件工程背景的迭代、验收和回退说明。
- 生成经过完整性检查的私人 Alpha DMG，并记录并行工作结束后的两分钟实机验收门。

本版本是私人本机 Alpha，不是已签名公证的公共发行版，也不改变当前语料完成度或科学验证状态。
