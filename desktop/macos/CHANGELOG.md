# macOS Desktop Changelog

## 0.4.0-preview.1 — 未发布

- 新增 macOS 原生 `.aresearch` 文件选择器；网页只接收短期 `selection_id`，不接收或返回本机路径。
- 官方资料包由共享核心统一验证发布者策略、签名、哈希、身份、权利范围与只读仓库；桌面层不维护自己的信任白名单。
- 保留 v12 本机可编辑维护工作区，同时把官方资料包作为第二个不可变来源；二者不复制、不覆盖。
- 新增官方资料库/本机工作区来源切换和四类横向检索；官方结果只使用 `source_scope/source_id/entity_uid`，不伪造本机数字 ID。
- 资料包不含 PDF 或图片二进制时，相应按钮明确禁用，仍展示题目、DOI、页码、图注或原文摘录。
- 新增 DeepSeek BYOK 状态、保存与删除引导；离线搜索无需 API 密钥。
- 桌面版本只从 `version.json` 读取，DMG 文件名随版本生成，保留 `0.3.0-preview.1` 回退身份。

本节仅记录已经完成定向测试的开发候选；尚未执行最终 App 构建、DMG、全套测试或实机验收。

## 0.3.0-preview.1 — 2026-08-01

- 将产品入口收敛为个人科研工作台 App；旧浏览器、导师只读和 ngrok 启动器只保留迁移提示。
- 集成核心提交 `9aa461a` 的签名研究简报与桌面产品契约。
- 加入新的 Auto Research 书页、证据节点与验证标记图标。
- 修复 ad-hoc 重建后 macOS 索要“登录钥匙串密码”的问题：预览版不读取或删除旧 Keychain 项。
- 历史继续使用 AES-256-GCM；预览期随机密钥保存在 Application Support 私有目录并限制为 `0600`。
- 明确当前只交付稳定 macOS 演示版；路径、资料包与安全凭据接口为未来 Windows 留出迁移边界，但本阶段不开发 Windows。
- 固化 `.aresearch` 官方资料包、用户私人库、本机状态和 BYOK 的分层方案。

本版本仍依赖开发机项目目录，且未正式签名、公证；它是稳定演示候选，不是可公开分发的最终产品。

## 0.2.0-alpha.1 — 2026-07-30

- 修复关闭并重新打开 App 后图书管理员对话历史消失的问题。
- 保持 pywebview 私人模式，不使用持久化浏览器 localStorage 保存科研对话。
- 使用 macOS Keychain 保存设备本地 AES-256 密钥。
- 使用 AES-256-GCM 将会话正文、回答、结果和元数据认证加密后写入 Application Support。
- 加密历史与科学 SQLite、PDF、搜索索引和模型缓存分离。
- 桌面会话接口继续受随机 loopback 端口、HttpOnly Cookie 和同源检查保护；普通浏览器和公开只读服务没有该接口。
- 加密层不可用时 fail closed：显示警告且不降级为明文持久化。

本版本仍是私人 macOS Alpha。加密本地历史不能替代正式代码签名、公证、威胁建模和公开发布安全审计。

## 0.1.0-alpha.1 — 2026-07-30

- 建立独立 `desktop/macos/` 产品层，不复制现有前端或证据核心。
- 添加 pywebview/WKWebView 原生窗口启动器。
- 使用随机 loopback 端口承载现有本地服务，隐藏浏览器和固定端口。
- 将生产数据库与图表资产保留在外部项目工作区，不打包进应用。
- 添加只读数据库与前端资源冒烟检查。
- 用真实 HTTP 响应验证 CSV、XLSX、Markdown 和 JSONL 四类导出。
- 添加 Apple Silicon PyInstaller `.app` 构建、验证和 DMG 入口。
- 添加工作树干净检查、更新前 SQLite 备份、上一版应用保留和安全更新入口。
- 每次构建在应用内部写入核心 commit、核心版本、数据策略和工作树状态清单。
- 添加面向非软件工程背景的迭代、验收和回退说明。
- 生成经过完整性检查的私人 Alpha DMG，并记录并行工作结束后的两分钟实机验收门。

本版本是私人本机 Alpha，不是已签名公证的公共发行版，也不改变当前语料完成度或科学验证状态。
