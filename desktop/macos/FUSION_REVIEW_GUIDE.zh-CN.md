# Auto Research 0.9.1 Fusion GUI 体验版使用说明

## 这是什么版本

这是 `0.9.1-preview.1` / build `19`，只用于审核新的科研工作台界面。它不是0.8完整功能版的替代品。

- 文献：读取启动时生成的独立只读快照。
- 实验：只显示明确标记的合成CSV，不读取或写入您的私人实验库。
- AI、上传、提取、确认、PDF、导出和资料包操作：全部停用，不会调用模型或产生费用。
- 外观与密度：可以保存；“已检查”和演示AI建议只保留到本次关闭窗口。

窗口顶端和状态栏会一直显示“Fusion GUI体验版 · 文献只读 · 实验为合成示例”。如果没有看到这句话，请关闭App，不要继续操作。

## 安装与打开

1. 完全退出正在运行的 Auto Research。
2. 打开 `Auto-Research-0.9.1-preview.1-macOS-arm64.dmg`。
3. 把 `Auto Research.app` 拖到“应用程序”，选择“替换”。
4. 在“应用程序”中打开 Auto Research。若macOS提示未公证，请关闭提示，然后在“应用程序”里按住Control点击App并选择“打开”；不要关闭Gatekeeper或其他系统安全保护。
5. 打开“设置 → 关于”，核对版本为 `0.9.1-preview.1`、build `19`。

维护者安装脚本会先把0.8 build18保存为非 `.app` 回退副本。若安装或签名验证失败，它必须恢复旧版而不是留下半成品。

## 建议审核顺序

1. **文献**：在左侧选择不同论文，确认中央标题/证据和右侧检查器同步变化；“开始自动提取”应禁用并标记 `0.9.2+`。
2. **搜索**：确认左侧来源/类型、中央信息流和右侧证据检查器形成四区，不出现旧宣传页或卡片墙。
3. **实验**：切换“硬度测量/样品信息”，点击单元格和列标题，使用方向键、Home/End、PageUp/PageDown；在右侧修改角色、意义和单位，确认只影响当前会话。点击“查看演示AI建议”后必须明确显示“未调用模型”。
4. **资料包**：确认只展示结构与安全边界，所有导入、回退和导出按钮均停用。
5. **设置**：切换跟随系统/日间/夜间与舒适/紧凑，关闭再打开后外观应保持；English、AI密钥和数据操作应显示计划支持或停用。
6. **键盘**：`⌘1…4`切换四个工作区，`⌘K`打开命令面板，`⌘,`打开设置，Escape关闭命令面板或窄窗口抽屉。
7. **窄窗口**：缩窄窗口，确认检查器变抽屉；继续缩窄时上下文栏也变抽屉；最窄时活动导航移到底部。抽屉关闭后焦点应回到触发按钮。

## 如何反馈

请只评价0.9.1的界面骨架：四区结构、信息密度、文献/搜索布局、CSV网格、检查器、设置、日夜主题和窄窗口。用户明确认可后，项目才会依次开发：

1. 0.9.2 搜索详情标签与内置PDF返回链；
2. 0.9.3 自动提取主流程；
3. 0.9.4 私人实验真实表格与核验曲线；
4. 0.9.5 资料包、条目、图表及CSV/XLSX真实导出。

若需要恢复0.8完整功能版，请先关闭0.9.1，再让维护者使用已验证的build18 `.app.rollback` 恢复；不要自行移动Application Support内的数据文件。
