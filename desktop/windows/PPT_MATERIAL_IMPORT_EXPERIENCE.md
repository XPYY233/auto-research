# Windows 资料包导入体验 PPT 素材

## 用户痛点

科研用户拿到资料包后，不知道程序是在复制、验签、安装还是卡死；失败提示如果暴露本机路径，也会增加隐私和排障成本。

## 交互方案

内部保留与 macOS 一致的十段稳定状态，界面合并为“检查文件—验证资料包—安装—准备离线搜索—完成”五步，并把真实字节进度与阶段进度分开显示。

## 安全边界

Windows 进度壳只消费不透明 package handle，不读取真实路径、不调用 product 核心；取消只允许在 `activate` 前，激活开始后禁止中断，所有错误和摘要均为 path-free 白名单 DTO。

## 测试证据

Mac 上使用假导入器验证阶段严格单调、字节进度不倒退、单活动导入锁、激活前取消、短等待原因、任意异常路径清洗和成功摘要；本阶段完成后 Windows 专属轻量测试为 56 项通过。

## Windows 正式版价值

用户双击或拖入 `.aresearch` 后能清楚知道当前在做什么、为什么需要等待、何时还能取消；失败不会损坏旧资料库，成功后直接进入离线搜索，形成真正“导入即用”的体验。
