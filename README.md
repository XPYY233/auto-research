# Auto Research

用于文献数据与图表提取、来源核验、检索和审核的个人桌面工作台。
保留 item、finding、table、figure 四类证据、受控 AI 调用、资料包和私人表格能力。

**项目正在工程重建，尚未形成通过干净 Mac 验收的新交付版。**
